# React Todo App with API

A robust, production-ready Todo application built with **React** and **TypeScript**. This project focuses on managing complex UI states, performing asynchronous CRUD operations via a REST API, and ensuring code quality with automated testing.

## 🔗 [Live Demo](https://SergiyKusiy.github.io/react_todo-app-with-api/)

---

## 🛠 Tech Stack

- **React** — Functional components, custom hooks, and advanced state management.
- **TypeScript** — Static typing for reliable data flow and API integration.
- **SASS (SCSS)** — Modular styling following the **BEM** methodology.
- **Fetch API** — Handling GET, POST, PATCH, and DELETE requests with error boundaries.
- **Cypress** — End-to-end testing to verify all user interactions.
- **Vite** — Optimized build tool for a fast development experience.

## 🌟 Key Features

- **Full CRUD Lifecycle:** Create, read, rename (inline editing), and delete tasks synced with a remote server.
- **Smart Toggling:** Individual task completion or bulk "Toggle All" functionality.
- **Optimistic UI:** Immediate visual feedback with loading overlays during API synchronization.
- **Validation & Error Handling:** Real-time validation for empty titles and descriptive error notifications for failed requests.
- **Advanced Filtering:** Quick navigation between All, Active, and Completed tasks.
- **Keyboard Support:** Save changes with `Enter` and cancel editing with `Esc`.

## ⚙️ Installation & Setup

1.  **Clone the project:**

    ```bash
    git clone [https://github.com/SergiyKusiy/react_todo-app-with-api.git](https://github.com/SergiyKusiy/react_todo-app-with-api.git)
    ```

2.  **Install dependencies:**

    ```bash
    npm install
    ```

3.  **Run the app:**
    ```bash
    npm start
    ```

## 🧪 Testing

To run the integrated Cypress tests:

```bash
npm test
```
